# FIKRAN GLOBAL TECHNOLOGY LTD — Corporate Website

Premium responsive multi-page website starter built from the approved FIKRAN-TECHNOLOGY Master Blueprint.

## Pages
Home, About, Departments, Services, Products, Developer, Vendor, Business, Contact, Login, Register and Careers.

## Run locally
Open `index.html` in a browser, or use a local static server. No build step is required.

## Deploy to Netlify
1. Extract this ZIP.
2. Upload the extracted project folder contents to a new Netlify deploy, or push the folder to GitHub and connect the repository.
3. Set the publish directory to `.` (the project root). No build command is required.
4. Ensure `index.html` is at the published root.

## Important implementation notes
- Login and registration are frontend demonstration interfaces only. They do not authenticate users or store account data.
- Contact form is a frontend demonstration and does not send messages.
- No payment, NIN/BVN, telecom, or other regulated integration is represented as active.
- Connect the approved Django REST Framework backend, authentication, database, provider APIs and security controls before production use.
- Do not place API keys, secrets, private credentials or sensitive customer data in frontend JavaScript.
